Твоя первая лабораторная
Запуск на Маке

Код подготовлен. Распакуй архив и перенеси всю папку в постоянное место, например Документы → telegram-ai-lab1. После создания БД папку лучше не перемещать: имя хранилища определяется её путём.

1. Установи две программы один раз

Python 3.12: при установленном Homebrew открой Терминал (⌘ + пробел) и выполни:

brew install python@3.12

Если Homebrew ещё нет — официальная инструкция установки. В конце выполни команды из Next steps, затем команду выше.

Docker Desktop: скачай, перетащи в «Программы» и открой. Для Apple M… выбирай Apple silicon, для Intel — Intel. Процессор указан в  → Об этом Mac.

2. Получи два ключа

Telegram: открой @BotFather, отправь /newbot, выбери имя и username, сохрани выданный токен.

Модель: войди в OpenRouter → Keys, нажми Create Key и скопируй ключ. Мастер предложит актуальные бесплатные модели с temperature. Доступность и лимиты определяет OpenRouter.

Ключи вводи только в окне настройки на своём Маке. При скрытом вводе символов не видно — вставь через ⌘ + V и нажми Enter. Файл .env не публикуй.

3. Запусти

Дважды щёлкни Запустить.command. Первое скачивание библиотек займёт несколько минут. Введи токен Telegram, прокси (Enter, если не нужен), ключ модели и выбери модель. При повторном запуске сохранённые настройки вводить не надо.

Если .command не открывается: в Терминале напечатай cd , перетащи папку проекта в окно, нажми Enter, затем выполни:

bash scripts/mac.sh run

Открой своего бота, отправь /start и «Объясни, что такое список в Python». Окно Терминала оставь открытым. Остановка — Control + C.

4. Что умеет бот

/studyОбъясняет программирование
/translateПереводит; например «На английский: завтра экзамен»
/quizПроверяет знания; сначала назови тему
/settings 0.7Меняет temperature: 0.0, 0.3, 0.7, 1.0
/resetОчищает историю; настройки сохраняются

5. Проверки, эксперимент и отчёт

Проверить.command запускает автоматические проверки без настоящих API.

Эксперимент.command делает 12 независимых запросов и два запроса для сравнения инструкций. Перед каждым основным запросом очищается отдельная история эксперимента; твои личные диалоги сохраняются. Вызовы обращаются к выбранной модели и используют её лимиты.

Затем откроется отчёт. Внеси ФИО и группу, проверь реальные ответы и дополни выводы. Зелёные поля редактируются кликом. «Скачать с правками» сохраняет HTML, «Печать / сохранить PDF» — PDF. Отдельный запуск отчёта: Отчёт.command.

Повторная генерация заменяет ручные правки — сохраняй отредактированную копию отдельно.

6. Перед сдачей

Открой ЗАЩИТА.html: как сохранить настоящую историю OpenCode и объяснить отказы сервисов. OpenCode.command открывает проект в OpenCode, а Сохранить-чат.command экспортирует выбранную тобой сессию.

Покажи три режима. Вторым Telegram-аккаунтом проверь разделение историй. Перезапусти бот и проверь сохранность контекста. Карта файлов и команды — в README.md.

До запуска с твоими ключами настоящая модель и Telegram не проверены. Экспериментальные ответы не выдуманы: они появятся после запуска эксперимента.

Если что-то не работает

Docker недоступен — открой Docker Desktop. Модель не отвечает — проверь интернет, ключ и её доступность. Telegram Conflict — останови второй процесс с тем же токеном. Системные защиты macOS отключать не нужно: используй запуск через Терминал.
